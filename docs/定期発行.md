# 定期発行

毎月同じ内容を請求している取引先を、自動で発行できます。使いたい人だけの機能です。

## 全体の流れ

```
毎日 9:00
  ↓
run-due が動く
  ↓
今日が発行日の取引先を探す
  ↓
PDFを作る（＋設定していればメール送信）
```

## 1. 取引先ごとに設定する

```bash
seikyusho-kun schedule add "株式会社ABC"
```

聞かれること:

| | 例 |
|---|---|
| 毎月いつ発行するか | 末日 / 1日 / 15日 / 25日 / 任意の日 |
| 毎月の名目 | サイト保守・運用費 |
| 毎月の金額 | 5000 |
| 支払期限 | 発行月の末日 / 翌月末 / 30日後 |
| 発行後に自動でメールを送るか | **既定は「送らない」** |

`31日` を指定した月に31日がない場合（2月など）は、その月の末日に発行されます。

設定は取引先のJSONに入ります。直接編集してもかまいません。

```json
{
  "name": "株式会社ABC",
  "email": "keiri@example.com",
  "schedule": {
    "day": "末日",
    "item": "サイト保守・運用費",
    "amount": 5000,
    "due": "翌月末",
    "email": false,
    "enabled": true
  }
}
```

`"enabled": false` にすると、設定を消さずに一時停止できます。

## 2. 何が出るか先に見る

```bash
seikyusho-kun run-due --dry-run              # 今日の分
seikyusho-kun run-due --dry-run --date 月末   # 月末に何が出るか
seikyusho-kun run-due --dry-run --date 2026-09-30
```

`--dry-run` を付けている間は、1件も発行されません。

## 3. 自動実行を登録する

```bash
seikyusho-kun schedule install           # 毎日 9:00
seikyusho-kun schedule install --at 8:30 # 時刻を指定
```

| OS | 使う仕組み | 登録先 |
|---|---|---|
| macOS | launchd | `~/Library/LaunchAgents/com.seikyusho-kun.daily.plist` |
| Linux | cron | `crontab -l` に1行 |
| Windows | タスクスケジューラ | タスク名 `com.seikyusho-kun.daily` |

解除するときは、

```bash
seikyusho-kun schedule uninstall
```

取引先ごとの設定は残るので、あとで登録し直せば同じように動きます。

**パソコンが起動していない時刻は実行されません。** macOS の launchd は、
指定時刻に起動していなかった場合、次に起動したときに1回だけ実行します。

## 4. 動いているか確かめる

```bash
seikyusho-kun schedule list   # 登録状況と対象の取引先
seikyusho-kun list            # 実際に発行された分
```

ログは `~/.seikyusho-kun/logs/run-due_YYYY-MM.log` に残ります。

```
2026-09-30T09:00:01.234Z ISSUED 株式会社ABC 202609-007 5500 /Users/.../請求書_株式会社ABC_202609-007.pdf
2026-09-30T09:00:03.101Z DONE issued=1 mailed=0 failed=0
```

## メールの自動送信について

**取引先ごとに `email: true` を設定したときだけ**、人の確認なしにメールが送られます。
既定は `false`（PDFを作るところまで）です。

自動送信を有効にする前に、必ず一度は手動で送って文面を確認してください。

```bash
seikyusho-kun send "株式会社ABC" --to 自分のアドレス --yes
```

メール設定が未完了だったり、取引先に宛先アドレスが無かったりする場合は、
PDFの発行だけ行い、ログに `MAIL_SKIP` を残して先に進みます。
**請求書の発行がメールの失敗で止まることはありません。**

## 発行後に別の処理を挟む

`config.json` の `hooks.afterIssue` は定期発行でも呼ばれます。
台帳への転記や会計ソフトへの連携はここに繋いでください。
実例は [`examples/afterIssue-hook.example.sh`](../examples/afterIssue-hook.example.sh) にあります。

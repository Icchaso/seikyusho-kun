# テンプレートのカスタマイズ

「もう自社の請求書フォーマットがある」「色だけ変えたい」——
やりたい深さに応じて3段階あります。

## 段階1: 色とロゴだけ変える

いちばん簡単です。`modern` テーマに切り替えて、ロゴとメインカラーを設定します。

```bash
seikyusho-kun theme use modern
seikyusho-kun init          # ロゴ画像のパスとメインカラーを聞かれます
```

`config.json` を直接いじってもかまいません。

```json
{
  "theme": "modern",
  "accentColor": "#2f6fb2",
  "issuer": { "logo": "~/Pictures/logo.png" }
}
```

ロゴは PNG / JPG / SVG が使えます。PDFに埋め込まれるので、あとから画像ファイルを
移動しても発行済みのPDFは崩れません。

## 段階2: 自分で細部を編集する

内蔵テンプレートを自分のフォルダに書き出します。

```bash
seikyusho-kun theme eject plain --as mine
seikyusho-kun theme use mine
```

`~/.seikyusho-kun/templates/mine/` に3つのファイルができます。

| ファイル | 役割 |
|---|---|
| `theme.css` | **ここを編集します。** 色・線・余白・文字サイズ |
| `invoice.njk` | 構造そのものを変えたいとき。Nunjucks（Jinja2 とほぼ同じ書き方） |
| `base.reference.css` | 共通の骨格。読むだけで、変更は `theme.css` で上書きします |

編集したら必ず出力を見て確かめてください。

```bash
seikyusho-kun new --to "テスト商事株式会社" --item "テスト項目" \
  --amount 100000 --due 月末 --yes --out /tmp/preview.pdf --open
```

### 主なクラス名

| クラス | 場所 |
|---|---|
| `.hd` / `.hd-title` / `.hd-meta` | 上部（「請求書」・請求書番号・発行日） |
| `.to` / `.to-name` / `.to-contact` | 宛先 |
| `.from` / `.from-name` / `.from-logo` | 発行者 |
| `.lead` | 挨拶文 |
| `.grand` / `.grand-label` / `.grand-value` | 合計金額の帯 |
| `.due` | お支払期限 |
| `.items` | 明細テーブル（`.sum` `.total` `.blank` が中の行） |
| `.bank` | 振込先 |
| `.remarks` | 備考 |
| `.ft` | フッター |

### 崩さないための約束

1. **`.ft` の `margin-top: auto` を消さない。**
   これがフッターを紙の下端に押し下げています。
2. **文字サイズは固定値でなく CSS変数を上書きする。**
   明細が増えたときの自動縮小（密度段 d1〜d4）が効かなくなります。

   ```css
   /* ✕ これをやると自動調整が壊れる */
   .items { font-size: 9pt; }

   /* ○ こう書く */
   body { --fs: 9pt; }
   ```
3. **変更したら明細1件と20件の両方でPDFを出す。**
   1ページに収まるかは実際に出さないと分かりません。
4. 横幅は `%` で。固定 `px` を入れると長い社名で横にはみ出します。

### 使える CSS変数

```css
:root {
  --ink:        #1a1a1a;  /* 本文の色 */
  --muted:      #6b6b6b;  /* 補足の色 */
  --rule:       #2b2b2b;  /* 太い罫線 */
  --rule-soft:  #8c8c8c;  /* 細い罫線 */
  --bg-head:    #f4f4f4;  /* 明細の見出し行 */
  --bg-total:   #e6e6e6;  /* 合計行 */
  --accent:     #2f6fb2;  /* メインカラー（config.accentColor が入る） */
  --font:       "Hiragino Sans", ...;  /* 本文書体 */
  --font-num:   Arial, ...;            /* 数字の書体 */
}
body {
  --fs: 10pt;      /* 本文 */
  --fs-sm: 8.5pt;  /* 補足 */
  --gap: 9mm;      /* ブロック間の余白 */
  --title: 28pt;   /* 「請求書」 */
  --grand: 22pt;   /* 合計金額 */
  --row-min: 30px; /* 明細の行の高さ */
}
```

## 段階3: 手元の請求書に寄せる（Claude Code）

いま使っている請求書のPDF・画像・Excelのスクリーンショットを Claude Code に見せて、
こう頼むのが一番早いです。

> 「`~/.seikyusho-kun/templates/mine/theme.css` を、この請求書の見た目に合わせて書き換えて。
> 直したら実際にPDFを出して見比べて」

同梱のスキルに、崩さないための注意と検証手順が書いてあるので、
Claude が出力を確かめながら直します。

## 元に戻したいとき

```bash
seikyusho-kun theme use plain
```

自作テンプレートのフォルダは消えないので、いつでも `theme use mine` で戻せます。

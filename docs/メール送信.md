# メール送信

使いたい人だけの機能です。設定していなければ `send` は何もしません。

## 安全のしくみ

**このツールは、あなたが `--yes` を付けるまでメールを送りません。**

```bash
seikyusho-kun send "株式会社ABC"
```

これは宛先・件名・添付・本文を画面に出すだけで終わります。中身を読んで問題なければ、

```bash
seikyusho-kun send "株式会社ABC" --yes
```

で実際に送信します。対話できる環境なら、`--yes` なしでも最後に
「この内容で送信しますか？」と聞かれます。

## どちらで送るか選ぶ

```bash
seikyusho-kun send --setup
```

### Resend（おすすめ）

APIキー1つで始められます。

1. [resend.com](https://resend.com) にサインアップ
2. 自分のドメインを追加して、表示される DNS レコードを設定
   （**自分のアドレスから送るために必要**）
3. API Keys からキーを作って、`send --setup` で貼り付ける

無料枠は **3,000通/月・100通/日・ドメイン3つまで**、添付は1通40MBまでです。
請求書PDFは大きくても数百KBなので、まず足りなくなりません。

ドメインを検証するまでは `onboarding@resend.dev` からの自分宛てテスト送信だけができます。

### SMTP

いま使っているメールをそのまま使えます。DNS の設定は要りません。

| | ホスト | ポート | パスワード |
|---|---|---|---|
| Gmail | `smtp.gmail.com` | 587 | [アプリパスワード](https://myaccount.google.com/apppasswords)（通常のパスワードでは通りません） |
| エックスサーバー | `svXXXX.xserver.jp` | 587 | メールアカウントのパスワード |
| さくらのレンタルサーバ | `初期ドメイン` | 587 | メールアカウントのパスワード |

## 認証情報の置き場所

APIキーとパスワードは `~/.seikyusho-kun/.env` にだけ保存されます。
本人だけが読める権限（600）が付きます。

```
RESEND_API_KEY=re_xxxxxxxx
SMTP_USER=you@example.com
SMTP_PASS=xxxxxxxxxxxx
```

**このファイルは共有もコミットもしないでください。**
CI などで使う場合は、同じ名前の環境変数を渡せば `.env` がなくても動きます。

## 使い方

```bash
# 直近に発行した分を送る
seikyusho-kun send

# 取引先を指定して、その最新分を送る
seikyusho-kun send "株式会社ABC"

# 請求書番号を指定する
seikyusho-kun send --no 202609-001

# 自分宛てにテスト送信する
seikyusho-kun send "株式会社ABC" --to you@example.com --yes

# 添付なしで送る
seikyusho-kun send "株式会社ABC" --no-attachment
```

宛先は取引先の `email` から取ります。登録は次のどちらかで。

```bash
seikyusho-kun clients add "株式会社ABC"
```

一度 `--to` なしで送信に成功すると、その宛先が取引先に記録されるので、
次回からは指定不要になります。

## 文面を変える

```bash
seikyusho-kun send --eject-template
```

`~/.seikyusho-kun/templates/mail/invoice.txt` が作られます。
**1行目が件名、2行目以降が本文**です。

差し込めるもの:

| 差し込み | 中身 |
|---|---|
| `{client}` / `{honorific}` | 取引先名 / 御中・様 |
| `{contactLine}` | 「担当者名 様」の行（担当者未登録なら空） |
| `{issuer}` / `{rep}` | 自分の屋号 / 代表者名 |
| `{total}` | お振込金額（源泉徴収後） |
| `{totalGross}` | 税込合計 |
| `{due}` / `{issueDate}` | 支払期限 / 発行日 |
| `{invoiceNo}` | 請求書番号 |
| `{year}` / `{month}` | 発行年 / 発行月 |

## 送信済みかどうか

```bash
seikyusho-kun list
```

`送信済 2026-09-05` のように出ます。すでに送った請求書をもう一度送ろうとすると
警告が出ますが、送ること自体はできます。

## 送れないとき

| メッセージ | 対処 |
|---|---|
| `メール送信が未設定です` | `send --setup` を実行 |
| `RESEND_API_KEY が見つかりません` | `send --setup` でキーを入れ直す |
| Resend: `domain is not verified` | Resend の管理画面でドメインの DNS 設定を完了させる |
| Gmail: `Username and Password not accepted` | 通常のパスワードではなくアプリパスワードを使う |
| `添付するPDFが見つかりません` | PDFを移動・削除した可能性。`--pdf` でパス指定するか再発行する |

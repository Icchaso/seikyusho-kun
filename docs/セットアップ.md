# セットアップ

## 1. 準備するもの

| | |
|---|---|
| Node.js | 18.17 以上（[nodejs.org](https://nodejs.org/) から入れられます） |
| ブラウザ | Google Chrome / Microsoft Edge / Chromium / Brave のどれか1つ |

PDFはブラウザのエンジンで作ります。追加のソフトは要りません。

Node.js が入っているかは、ターミナルでこう打つと分かります。

```bash
node -v
```

`v18.17.0` のように数字が出れば大丈夫です。

## 2. 初期設定

```bash
npx seikyusho-kun init
```

順番に聞かれるので答えていきます。あとから何度でも変更できます。

| 聞かれること | 例 | 補足 |
|---|---|---|
| 屋号 / 会社名 | サンプル工房 | 請求書の発行元として出ます |
| 代表者名 | 見本 太郎 | 省略できます |
| インボイス登録番号 | T1234567890123 | **未登録（免税事業者）なら空欄のまま Enter**。空欄なら請求書に表示されません |
| 電話・メール・郵便番号・住所 | | 省略できます |
| 振込先 | サンプル銀行 本店営業部 普通 1234567 | 空欄にすると振込先の欄ごと消えます |
| 金額の入れ方 | 税抜（外税）/ 税込（内税） | 一般的なのは税抜 |
| 源泉徴収 | する / しない | 個人事業主で報酬から天引きされる方は「する」 |
| デザイン | plain / modern / compact | あとから変えられます |
| PDFの保存先 | `~/Documents/請求書/{year}` | `{year}` は年に置き換わります |

最後に「Claude Code から頼めるようにしますか？」と聞かれます。
Claude Code をお使いなら「はい」を選ぶと、`~/.claude/skills/` にスキルが入り、
**日本語で頼むだけで請求書が出せる**ようになります。

## 3. 動くか確かめる

```bash
npx seikyusho-kun doctor
```

実際にサンプルの請求書PDFを1枚作ってみて、全部にチェックが付けば準備完了です。

```
✔ PDF生成エンジン (Chrome)  Google Chrome 152.0.7977.76
✔ 設定ファイル              ~/.seikyusho-kun/config.json
✔ 発行者情報                サンプル工房 / 登録番号 T1234567890123
✔ テーマ                    plain（内蔵）
✔ 出力先フォルダ            ~/Documents/請求書/2026
✔ PDF生成テスト             サンプル請求書を生成 → A4 1ページ（密度 d1, 310KB）
```

## 4. 1枚出してみる

```bash
npx seikyusho-kun new
```

聞かれるとおりに答えると、保存先にPDFができます。

## 毎回 `npx` を打つのが面倒なとき

```bash
npm install -g seikyusho-kun
```

これで `seikyusho-kun` だけで呼べるようになります。`seikyu` でも動きます。

## Chrome が見つからないと言われたら

インストール場所が特殊な場合は、環境変数で教えてあげてください。

```bash
# macOS / Linux の例
export SEIKYUSHO_CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"

# Windows (PowerShell) の例
$env:SEIKYUSHO_CHROME = "C:\Program Files\Google\Chrome\Application\chrome.exe"
```

毎回打たなくていいように `.zshrc` / `.bashrc` に書いておくと楽です。

## 設定を直接編集する

`~/.seikyusho-kun/config.json` をエディタで開けば、対話に出てこない項目も変えられます。

| 項目 | 何を決めるか | 例 |
|---|---|---|
| `invoiceNoPattern` | 請求書番号の形式 | `{yyyy}{mm}-{seq:3}` → `202609-001` |
| `fileNamePattern` | ファイル名 | `請求書_{client}_{no}` |
| `minRows` | 明細テーブルの最小行数（足りない分は空行の罫線で埋まる） | `5` |
| `greeting` | 挨拶文 | `下記の通りご請求申し上げます。` |
| `notes` | 備考欄の既定（配列） | |
| `tax.rounding` | 消費税の端数処理 | `floor` / `round` / `ceil` |

`invoiceNoPattern` で使える差し込み: `{yyyy}` `{yy}` `{mm}` `{dd}` `{seq}` `{seq:3}`。
`{mm}` を含めると連番は毎月1に戻り、`{yyyy}` だけなら毎年戻ります。

設定例の全体は [`examples/config.example.json`](../examples/config.example.json) にあります。

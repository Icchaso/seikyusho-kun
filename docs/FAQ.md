# よくある質問

## 使い方

### Q. 消費税は税抜と税込どちらで入力しますか？

`init` で選んだ設定によります（既定は**税抜＝外税**）。あとから変えるには
`config.json` の `tax.mode` を `exclusive`（税抜）か `inclusive`（税込）にします。
`new` の対話中も「金額は？（税抜）」のように、いま何を聞かれているか表示されます。

### Q. 軽減税率（8%）の品目を混ぜられますか？

できます。その品目に `--rate 8` を付けてください。

```bash
seikyusho-kun new --to "株式会社ABC" \
  --item "コンサルティング" --amount 100000 \
  --item "手土産代" --amount 5000 --rate 8 \
  --due 月末
```

税率ごとの区分行が自動で増え、8%の品目に `※` が付きます。
これは適格請求書の必須記載事項です。

### Q. 源泉徴収に対応していますか？

しています。`init` で「源泉徴収を計算しますか？」に「はい」と答えるか、
`config.json` の `tax.withholding` を `true` にしてください。

税抜金額に対して 10.21%（1回の支払が100万円を超える部分は 20.42%）を計算し、
「お振込金額」として差し引き後の金額を表示します。

消費税額を請求書上で区分表示しているため、税抜金額を源泉徴収の対象にしています
（国税庁の取扱いによる）。

### Q. インボイス（適格請求書）に対応していますか？

登録番号・取引年月日・取引内容・税率ごとに区分した合計額・税率ごとの消費税額・
受領者名を記載します。

登録番号を空欄にしておけば表示されないので、免税事業者の方もそのまま使えます。

**最終的な適合の判断は利用者ご自身でお願いします。** 迷う点は税理士にご確認ください。

### Q. 請求書番号を自分の形式にしたい

`config.json` の `invoiceNoPattern` を変えます。

| 書き方 | 出る番号 |
|---|---|
| `{yyyy}{mm}-{seq:3}` | `202609-001`（既定） |
| `INV-{yyyy}-{seq:4}` | `INV-2026-0001` |
| `{yy}{mm}{dd}-{seq}` | `260905-1` |
| `{seq:5}` | `00001`（通し番号） |

`{mm}` を含めると毎月1に戻り、`{yyyy}` だけなら毎年戻り、どちらも無ければ通し番号です。

1枚だけ番号を指定したいときは `--no 2026-09-100` を付けます。

### Q. 番号が飛んでしまった

`~/.seikyusho-kun/counter.json` に連番が入っているので直接直せます。
発行に失敗したときは自動で戻すようにしていますが、手で消したPDFの分は戻りません。

### Q. すでに発行した請求書を作り直したい

同じ番号を指定して出し直せます。同名のファイルがある場合は `-2` が付くので、
上書きしたい場合は古い方を削除してください。

```bash
seikyusho-kun new --to "株式会社ABC" --item "..." --amount 150000 \
  --due 月末 --no 202609-001 --out ~/Desktop/請求書_修正版.pdf
```

## レイアウト

### Q. 2ページになってしまいます

`plain` の場合、おおむね20行前後まで1枚に収まります。それを超えると自動で
2ページになり、各ページに明細の見出し行が繰り返され、ページ番号が入ります。

1枚に収めたいときは:

1. `--theme compact` を使う（余白が詰まって行数が稼げます）
2. 品名を短くする
3. 似た項目をまとめて1行にする

### Q. 明細の空行を減らしたい / 増やしたい

`config.json` の `minRows` を変えます（既定は5）。`0` にすると空行が出ません。

### Q. 押印欄がほしい

`theme eject` して `invoice.njk` に枠を足してください。
Claude Code に「発行者ブロックの下に押印欄を作って」と頼むのが早いです。

### Q. 見積書や納品書にも使えますか？

いまは請求書だけです。`theme eject` してタイトルと文言を書き換えれば、
見た目上は見積書として使えますが、番号の採番は請求書と共通になります。

## トラブル

### Q. `Chrome が見つかりません` と出ます

Google Chrome / Microsoft Edge / Chromium / Brave のどれかを入れてください。
入っているのに見つからない場合は場所を教えてあげてください。

```bash
export SEIKYUSHO_CHROME="/path/to/chrome"
```

### Q. 日本語が豆腐（□□□）になります

日本語フォントが無い環境です。macOS と Windows は標準で入っています。
Linux の場合は入れてください。

```bash
sudo apt install fonts-noto-cjk        # Debian / Ubuntu
```

### Q. `設定がまだありません` と出ます

`seikyusho-kun init` を先に実行してください。

### Q. データはどこにありますか

`~/.seikyusho-kun/` です。フォルダごとコピーすれば別のパソコンに移せます。
中の `.env`（メールの認証情報）だけは、共有先に応じて扱いに注意してください。

### Q. アンインストールしたい

```bash
npm uninstall -g seikyusho-kun
seikyusho-kun schedule uninstall   # 自動実行を登録していた場合（先に実行）
rm -rf ~/.seikyusho-kun            # データも消すなら
```

発行済みのPDFは保存先フォルダに残ります。

## 安全性

### Q. データが外部に送られることはありますか

ありません。設定・取引先・発行台帳はすべて自分のパソコンの中だけにあります。
外部と通信するのは、**自分でメール送信を設定して実際に送るとき**だけです。

### Q. APIキーはどこに保存されますか

`~/.seikyusho-kun/.env` に、本人だけが読める権限（600）で保存されます。
`config.json` には入りません。

### Q. 会社で使っても大丈夫ですか

MIT ライセンスなので商用利用できます。ただし請求書の内容と税務上の取り扱いの
責任は利用者にあります。導入前に一度、経理担当の方に出力を見てもらってください。
